# Faiz Atta — Portfolio Website

A premium, responsive Vue 3 portfolio for a full-stack web developer working with Laravel, Vue.js, REST APIs, and business applications.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```

## Customize

- Edit `src/data/portfolio.js` to update your email, phone number, LinkedIn URL, form endpoint, skills, projects, or experience.
- Contact details remain intentionally blank until real values are supplied.
- Project statuses are labeled honestly: the typing app is delivered; the other project cards are concepts.
- The contact form validates fields in the browser and will only be ready to deliver messages after a real endpoint is configured.

## Tech

- Vue 3 with Composition API
- Vite
- Tailwind CSS
- GSAP
- Lucide Vue icons
